# 简历编辑器检查与定位

## 职责

- `resumeChecks.ts`：缺失、格式与时间线问题的统一类型、文案格式化，以及模块、记录定位目标。
- `useProgress.ts`：沿用表单声明的检查规则和必填项完成度计算，生成模块问题清单与汇总列表；`collectResumeAdjustmentIssues` 将同一结果转为助手调整说明，不单独维护检查规则。
- `useModuleNav.ts`：编辑定位、展开与高亮；检查入口使用 `jumpToCheckTarget`，预览与搜索沿用各自入口。
- `panel/form/moduleSidebar/progress/index.vue`：一次统计问题分类数量，详情按模块分隔展示完成度和问题，并为每条问题提供修改入口。

## 约定

- 检查结果即时计算，不写入简历、备份或历史记录；不增加存储字段或迁移分支。
- 新规则沿用 `ResumeCheckIssue`（统一问题类型）。字段必填和格式规则继续由表单配置声明，不在界面或助手中另写字段清单。
- `ResumeCheckTarget.moduleKey`（模块编号）指定模块；`listPath`（记录数组路径）和 `record`（原记录引用）共同指定记录。定位时重新读取下标，删除、替换记录或切换简历后丢弃失效定位，不依赖问题生成时的序号。
- 日期冲突和未来日期定位到对应记录；时间空档定位到空档之后的记录；没有记录可定位的缺失项定位到模块。
- 同一问题列表同时用于展示和助手调整；问题等级只用于提示，不增加导出限制。
- 操作变化同步简历学习中心的中英文文案。是否运行构建、测试或浏览器验证遵守根目录 `AGENTS.md`。
