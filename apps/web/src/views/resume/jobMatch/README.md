# AI 岗位适配

- `/resume/job-match` 直接显示岗位定制表单与简历预览，不再显示入口卡片或功能选择页。
- 进入后左侧展示完整简历，右侧选择简历并填写目标岗位、可选公司和岗位说明；生成前固定输入并核对源数据，避免异步读取使用过期内容。
- 通过共用优化面板直接生成定制草稿，支持预览、前后对比及另存专属版本。仅调整已有事实，缺失事实保留为待补充项，原简历不覆盖。
- 另存时在 `usage.tags`（简历分类标签列表）中保留源标签并追加“公司 · 岗位”，公司为空时只使用岗位名称；相同标签不重复添加。
- 页面使用当前工作区高度，表单内部滚动，操作栏固定；容量充足时不显示数量，容量已满时在使用前提示并拦截。另存时再次核对容量。
- 离开页面会卸载当前任务并取消未完成执行，保存期间不能离开。保存与部分草稿行为见 `../components/aiOptimize/README.md`。
