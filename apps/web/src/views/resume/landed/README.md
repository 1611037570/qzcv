# 歇会儿

本目录独立维护「歇会儿」便签墙页面，入口位于导航最后的「更多」分类；组件与逻辑仅在本模块使用，不移入全局通用组件目录。

## 目录职责

- `index.vue`：页面标题、重新获取按钮及按钮状态。
- `components/noteWall.vue`：网格背景、便签列表与页面刷新入口。
- `components/noteCard.vue`：单张便签显示、主题配色、悬停、复制及自然尺寸测量。
- `composables/useNoteWall.ts`：初始化、整墙手动刷新、自动双张轮换、动画调度及卸载清理。
- `utils/layout.ts`：分区落点、实测尺寸边界与共用动效样式。
- `utils/content.ts`：纯文案选择、去重与便签数据创建。
- `data/quotes.ts`：便签墙专用短语录，按生活、成长、求职、自我接纳、陪伴与风景主题维护。
- `types.ts`：模块内共用的便签数据、位置与组件公开接口类型；组件统一使用 TypeScript 脚本。
- `config.ts`：数量、布局估算和动画、轮换时间配置。

## 行为约定

- 固定展示一百张自然尺寸便签，各分区允许多张；网格与便签外观由本模块维护。
- 自动轮换由整面墙唯一计时器控制：静止随机一至两秒后替换两张，新便签在明显不同的落点补位，优先填补空隙；整轮入场完成后重新计时，不累积刷新批次。可用便签不足两张时按实际数量轮换。
- 进出场各持续七百毫秒，首次显示、自动轮换和手动刷新共用同一套柔和动画。
- 手动“重新获取”更新整面墙的文案与分布，按钮在刷新期间反馈状态；不显示独立加载弹层。刷新开始前取消旧的自动轮换及异步动画，完整入场后恢复自动计时。
- 悬停便签不参与替换；刚开始离场的便签遇到悬停会恢复，整墙刷新也保留仍被悬停的内容及位置。
- 文案创建时统一转为字符串，原短句与本模块语录合并去重；首次展示也随机选句并避开同屏重复，展示与复制使用同一内容，不渲染配置对象。
- 位置计算使用实际便签尺寸，四周不叠加固定留白，仅预留旋转与动画防裁切空间。
- 动画版本和定时器由轮换逻辑统一维护，页面卸载及手动刷新时清理，旧任务不得修改新列表。
