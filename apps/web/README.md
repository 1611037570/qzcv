# @snowflake/web

基于 Vue 3 + Vite 的前端应用。

## 初始入口与产品页面信息

- 应用仅保留简历业务，根路径统一跳转 `/resume`，不再读取旧产品入口偏好。
- `site.config.ts` 统一声明简历页面的标题、描述、关键词与收录信息。
- 初始网页与客户端导航统一通过 `src/views/resume/seo/page.ts` 解析 `site.config.ts`，共享标题、描述、收录指令、社交标签与结构化数据。新增页面不再维护独立的页头脚本路由清单；语言切换仍同步页面信息。
- 构建时预渲染登记的公开路由，直接保存原有页面组件生成的界面与正文，不再额外追加介绍区。客户端导航仍同步页面信息；构建机首次需安装预渲染浏览器，部署需优先返回对应静态文件，详见 [公开页面说明](src/views/resume/seo/README.md) 与根目录 `deploy/nginx-resume.conf`。
- 范本与模板数量分别来自真实清单，构建时重新统计并写入公开页面的 SEO 描述；浏览器导航时也读取同一清单，避免手填数量过期。

## 配置入口

- 两端统一使用 `src/configs/index.ts` 作为应用配置入口，读取 `config`（应用配置对象）；保留现有配置模块和资源位置。
- 环境读取集中在 `src/configs/env.ts`；实际值写入被忽略的分环境文件 `.env.{运行模式}`，`.env.example` 只保留字段说明和空值。
- 本阶段内置模型仍由前端直连，环境中的密钥仍会进入浏览器代码；第三方接口与服务端代理不在本次改动范围。
